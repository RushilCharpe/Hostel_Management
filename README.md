# 🏠 Hostel Management System

A simple **Python-based hostel management system** with a colorful terminal UI powered by [Rich](https://github.com/Textualize/rich).  
This project helps track student entries and exits, reasons for going out, and provides a neat table view of all records.

---

## ✨ Features
- Add new student records (ID + Name).
- Log **OUT** with time and reason.
- Log **IN** with time.
- Show all records in a **styled Rich table**.
- Delete student records permanently.
- Data is stored in a **JSON file** for persistence.
